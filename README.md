# Social Network Friend Management System

## About the Project
A C++ project that demonstrates how user information and friendship relationships can be organized in a simplified social network.

## Features
- Add user records
- Manage friend relationships
- Display friends
- Search for users
- Remove friendships, if implemented

## Technologies Used
- C++
- Data Structures

## Concepts Used
Graphs, adjacency lists or matrices, functions, and classes, depending on implementation.

## How to Run
Compile and run the C++ source file.

## Learning Objective
To understand how graph data structures represent connections between users.
